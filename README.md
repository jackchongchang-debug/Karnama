# کارنما

برنامه‌ی شخصی مدیریت وظایف، پروژه‌ها و مشتریان؛ فارسی، راست‌به‌چپ، با تقویم شمسی و همگام‌سازی بین دستگاه‌ها.

## قابلیت‌ها

- **پروژه و وظیفه:** برد کانبان با ستون‌های دلخواه (کشیدن و رها کردن)، نمای فهرست، کپی پروژه و وظیفه، بایگانی
- **جزئیات وظیفه:** تاریخ شروع و پایان، ددلاین، یادآور با ساعت، وزن (برای محاسبه‌ی پیشرفت)، چک‌لیست، برچسب، اتصال به مشتری
- **وظایف تکرارشونده:** روزانه، هفتگی، ماهانه یا سالانه؛ با انجام هر نوبت، نوبت بعدی خودکار ساخته می‌شود
- **قالب‌ها و فرایندها:** مراحل یک فرایند را با فاصله‌ی زمانی تعریف کنید و با یک کلیک پروژه بسازید؛ یا هر پروژه را به قالب تبدیل کنید
- **تقویم شمسی** با جمعه‌ها و تعطیلات رسمی خورشیدی (تعطیلات قمری را در تنظیمات اضافه کنید)
- **نمودار گانت** شمسی و راست‌به‌چپ
- **یادداشت‌های شخصی** با رنگ و سنجاق
- **مدیریت مشتری:** پرونده‌ی مشتری، گزارش تماس، اسناد مالی (فاکتور، دریافتی، هزینه) و مانده حساب، فرصت‌های فروش با مراحل، پیگیری‌ها، پیش‌بینی درآمد ماهانه
- **داشبورد:** کارهای امروز و عقب‌افتاده، نمودار کارهای انجام‌شده، پیشرفت پروژه‌ها، درآمد پیش‌بینی‌شده
- **ورود اطلاعات** از ترلو (JSON) و اکسل (CSV)، و فایل پشتیبان
- **آفلاین:** روی گوشی و کامپیوتر به‌صورت اپ نصب می‌شود و بدون اینترنت کار می‌کند؛ با برگشتن اینترنت همگام می‌شود

## ساختار

- `web/` — برنامه (React + TypeScript + Vite، PWA). اطلاعات در IndexedDB همان دستگاه ذخیره می‌شود.
- `server/` — سرور همگام‌سازی (Node.js + Express + PostgreSQL). هم API را می‌دهد و هم خود برنامه را.

همگام‌سازی: هر رکورد زمان آخرین تغییر و نشانه‌ی حذف دارد. هر دستگاه تغییرات خودش را می‌فرستد و تغییرات بقیه را می‌گیرد؛ اگر یک رکورد روی دو دستگاه تغییر کرده باشد، تغییر جدیدتر می‌ماند.

## نصب روی سرور

پیش‌نیاز: یک سرور مجازی لینوکس با Docker، و یک دامنه یا زیردامنه که به IP سرور اشاره کند (برای HTTPS، که نصب برنامه روی گوشی به آن نیاز دارد).

```bash
git clone https://github.com/jackchongchang-debug/karnama.git
cd karnama
cp .env.example .env
nano .env          # DOMAIN، APP_PASSWORD و DB_PASSWORD را تنظیم کنید
docker compose up -d --build
```

بعد آدرس `https://دامنه‌ی-شما` را باز کنید، به **تنظیمات ← همگام‌سازی** بروید و با `APP_PASSWORD` وارد شوید. روی هر دستگاه دیگر هم همین کار را بکنید. برای نصب روی گوشی، در مرورگر گزینه‌ی «افزودن به صفحه‌ی اصلی» را بزنید.

به‌روزرسانی: `git pull && docker compose up -d --build`

پشتیبان پایگاه داده: `docker compose exec db pg_dump -U karnama karnama > backup.sql`

## توسعه

```bash
# برنامه
cd web && npm install && npm run dev      # http://localhost:5173

# سرور (به PostgreSQL نیاز دارد)
cd server && npm install
DATABASE_URL=postgres://user:pass@localhost/karnama APP_PASSWORD=secret npm start
TEST_DATABASE_URL=postgres://... npm test
```

در حالت توسعه، Vite درخواست‌های `/api` را به `localhost:4000` می‌فرستد.
