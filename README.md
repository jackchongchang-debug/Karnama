# کارنما

برنامه‌ی شخصی مدیریت وظایف، پروژه‌ها و مشتریان؛ فارسی، راست‌به‌چپ، با تقویم شمسی و همگام‌سازی بین دستگاه‌ها.

## قابلیت‌ها

- **پروژه و وظیفه:** برد کانبان با ستون‌های دلخواه (کشیدن و رها کردن)، نمای فهرست، کپی پروژه و وظیفه، بایگانی
- **جزئیات وظیفه:** تاریخ شروع و پایان، ددلاین، یادآور با ساعت، وزن (برای محاسبه‌ی پیشرفت)، چک‌لیست، برچسب، اتصال به مشتری
- **وظایف تکرارشونده:** روزانه، هفتگی، ماهانه یا سالانه؛ با انجام هر نوبت، نوبت بعدی خودکار ساخته می‌شود
- **قالب‌ها و فرایندها:** مراحل یک فرایند را با فاصله‌ی زمانی تعریف کنید و با یک کلیک پروژه بسازید؛ یا هر پروژه را به قالب تبدیل کنید
- **تقویم شمسی** با جمعه‌ها و تعطیلات رسمی خورشیدی (تعطیلات قمری را در تنظیمات اضافه کنید)
- **نمودار گانت** شمسی و راست‌به‌چپ
- **یادداشت‌های شخصی** با رنگ و سنجاق
- **مدیریت مشتری:** پرونده‌ی مشتری، گزارش تماس، اسناد مالی (فاکتور، دریافتی، هزینه) و مانده حساب، فرصت‌های فروش با مراحل، پیگیری‌ها، پیش‌بینی درآمد ماهانه
- **داشبورد:** کارهای امروز و عقب‌افتاده، نمودار کارهای انجام‌شده، پیشرفت پروژه‌ها، درآمد پیش‌بینی‌شده
- **ورود اطلاعات** از ترلو (JSON) و اکسل (CSV)، و فایل پشتیبان
- **آفلاین:** روی گوشی و کامپیوتر به‌صورت اپ نصب می‌شود و بدون اینترنت کار می‌کند
- **همگام‌سازی با گوگل‌درایو:** بدون سرور؛ اطلاعات در پوشه‌ی مخفی مخصوص برنامه در گوگل‌درایو خودتان نگه داشته می‌شود

## ساختار

همه‌ی برنامه در پوشه‌ی `web/` است (React + TypeScript + Vite، PWA) و سروری ندارد. اطلاعات در IndexedDB همان دستگاه ذخیره می‌شود.

همگام‌سازی: هر رکورد زمان آخرین تغییر و نشانه‌ی حذف دارد. برنامه یک فایل `karnama.json` را در پوشه‌ی مخفی برنامه (appDataFolder) در گوگل‌درایو می‌خواند، رکوردها را با اطلاعات دستگاه ادغام می‌کند (تغییر جدیدتر می‌ماند) و نتیجه را برمی‌گرداند. دسترسی برنامه فقط به همین پوشه است، نه به بقیه‌ی فایل‌های درایو.

## انتشار روی GitHub Pages

۱. در مخزن: **Settings ← Pages ← Source: GitHub Actions**. از این به بعد با هر تغییر در شاخه‌ی `main`، برنامه در `https://<نام‌کاربری>.github.io/karnama/` منتشر می‌شود.

۲. ساخت شناسه‌ی کلاینت گوگل (یک بار):
   - در [Google Cloud Console](https://console.cloud.google.com/) یک پروژه بسازید.
   - **APIs & Services ← Library**: «Google Drive API» را فعال کنید.
   - **OAuth consent screen**: نوع External، نام برنامه «کارنما»، و ایمیل خودتان را در Test users اضافه کنید.
   - **Credentials ← Create credentials ← OAuth client ID**: نوع Web application، و در Authorized JavaScript origins آدرس `https://<نام‌کاربری>.github.io` را بگذارید.
   - شناسه‌ی ساخته‌شده (`...apps.googleusercontent.com`) را در فایل `web/.env.production` بگذارید، یا در برنامه در **تنظیمات ← همگام‌سازی** وارد کنید.

۳. روی هر دستگاه برنامه را باز کنید، به **تنظیمات ← اتصال به گوگل‌درایو** بروید و با همان حساب گوگل وارد شوید. برای نصب روی گوشی، در مرورگر «افزودن به صفحه‌ی اصلی» را بزنید.

## توسعه

```bash
cd web && npm install && npm run dev      # http://localhost:5173
```

برای آزمایش همگام‌سازی در حالت توسعه، `http://localhost:5173` را هم به Authorized JavaScript origins اضافه کنید.
